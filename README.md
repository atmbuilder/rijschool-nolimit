# Rijschool No Limit

GitHub source of the production website currently hosted on Replit.

- Production domain: https://rijschoolnolimit.nl
- Replit deployment: https://website-assets-manager.replit.app
- Stack: React, TypeScript, Vite, Tailwind CSS
- Snapshot imported: 2026-08-17

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Source note

The application code mirrors the current Replit production project. Production photo assets are referenced from the current Replit deployment so the repository stays lightweight while the live site continues to use the same images and design.
